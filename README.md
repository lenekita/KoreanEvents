# Nuit de Séoul

Mini-site statique en français, prêt pour GitHub Pages.

## Publication

1. Créer un nouveau dépôt GitHub public, par exemple `nuit-de-seoul`.
2. Importer `index.html` et le dossier `assets` à la racine du dépôt.
3. Ouvrir **Settings → Pages**.
4. Choisir **Deploy from a branch**, puis **main** et **/(root)**.
5. Enregistrer et patienter quelques minutes.

Le site ne transmet aucune donnée. L'adresse e-mail et la localisation restent dans le navigateur et disparaissent à la fermeture ou au rechargement de la page.
